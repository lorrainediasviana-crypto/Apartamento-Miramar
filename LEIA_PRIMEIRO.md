# Apartamento Miramar — organização do estudo

Este pacote organiza a conversa; não cria um Projeto na interface do ChatGPT e não publica um ambiente de desenvolvimento.

## Estrutura

- 00_referencia_principal: regras de geometria e pendências da planta original.
- 01_voce_e_bento: proposta pessoal, independente da proposta da amiga.
- 02_amiga_e_tres_filhos: alternativa para mãe e três meninos.
- INSTRUCOES_DO_PROJETO.md: texto para as instruções do Projeto no ChatGPT.

A planta técnica original enviada pela usuária é a referência principal e está salva em [00_referencia_principal](00_referencia_principal/WhatsApp%20Image%202026-11-05%20at%2013.54.27.jpeg). Ao criar o Projeto do ChatGPT, adicionar também essa imagem como arquivo de referência. Não substituir a planta técnica por uma imagem gerada.

As imagens copiadas são referências visuais em revisão, não desenhos medidos nem aprovação técnica. Uma imagem posterior não se torna automaticamente aprovada. As preferências expressas e os pontos pendentes estão registrados nos documentos de cada proposta.

## Como usar no ChatGPT

1. Criar um Projeto com o nome Apartamento Miramar.
2. No menu desta conversa, usar Mover para projeto, se essa opção estiver disponível, e selecionar o Projeto.
3. Adicionar os documentos deste pacote e a planta original aos arquivos do Projeto. Se ZIP não for aceito, extrair e anexar os arquivos individualmente.
4. Copiar INSTRUCOES_DO_PROJETO.md para as instruções do Projeto.
5. Para novos estudos, abrir conversas separadas: Proposta A — Você e Bento; Proposta B — Amiga e três filhos.

Não é necessário publicar o ambiente de desenvolvimento para continuar o trabalho visual.
