## Estado do estudo

Imagens conceituais, sem validação dimensional. Preferências expressas e sugestões estão diferenciadas nos documentos de decisões. As imagens podem conter divergências; a planta técnica original sempre prevalece.

**A planta técnica original está salva em [00_referencia_principal](00_referencia_principal/WhatsApp%20Image%202026-11-05%20at%2013.54.27.jpeg).** Imagem conferida visualmente com a referência enviada na conversa. Este arquivo prevalece sobre as imagens geradas; por ser um recorte em JPEG, não substitui o projeto completo ou um levantamento medido.

Nenhum arquivo 3D editável foi produzido; as vistas 3D são imagens PNG. Este repositório preserva os documentos e as imagens selecionadas, não todo o histórico da conversa.
